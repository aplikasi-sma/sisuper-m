3 Pengalaman Belajar Pembelajaran Mendalam

Acuan utama butir 7–9 Lampiran 5 dan butir 8–10 Lampiran 6

  • 1. MEMAHAMI: Murid terlibat aktif mengonstruksi pengetahuan secara mendalam dari berbagai sumber/konteks, menghubungkan pengetahuan awal, menstimulasi berpikir, eksploratif, kolaboratif, dan menanamkan karakter.
  • 2. MENGAPLIKASI: Murid mengaplikasikan pemahaman secara kontekstual dalam situasi nyata, memecahkan masalah kontekstual, berpikir kritis (HOTS), dan mencari solusi inovatif.
  • 3. MEREFLEKSI: Murid mengevaluasi dan memaknai proses serta hasil belajar, menerapkan strategi berpikir, metakognisi (regulasi diri), dan meregulasi emosi dalam pembelajaran.

Prinsip PM, Saling Memuliakan & Integrasi KKA

Fondasi ekosistem pembelajaran dan tindak lanjut supervisi

  • Prinsip Pembelajaran Mendalam: Berkesadaran (mindful), Bermakna (meaningful), dan Menggembirakan (joyful) pada setiap pengalaman belajar.
  • Saling Memuliakan: Bahasa verbal & nonverbal yang menghargai keberagaman, keseimbangan gender, inklusif (termasuk penyandang disabilitas), dan aman secara psikis.
  • Integrasi KKA & CT: Penguatan Berpikir Komputasional (Computational Thinking) serta Koding dan Kecerdasan Artifisial (KKA) dalam strategi pembelajaran.

✨ Sinkronisasi Multi-Perangkat & Backup Cloud Otomatis
Data supervisi SMA NEGERI 1 LENTENG SUMENEP dapat disimpan secara realtime ke Google Firebase (Cloud Firestore / Realtime Database) sehingga dapat diakses bersama secara terpusat dari laptop, tablet, atau smartphone.
Status Firebase: 🟡 Mode Lokal (LocalStorage)
Belum tersinkron ke cloud
📖 Panduan 3 Langkah Membuat Firebase Gratis
  1. Buka console.firebase.google.com dan masuk dengan akun Google Anda.
  2. Klik Add Project (beri nama, misal Supervisi-SMAN1-Lenteng).
  3. Di menu samping, pilih Build > Firestore Database lalu klik Create Database (pilih lokasi terdekat asia-southeast2 Jakarta, dan centang mode Start in test mode).
  4. Di halaman utama Project Overview, klik ikon Web (</>) untuk mendaftarkan web app, lalu salin blok konfigurasi ke kotak di atas.
  5. Klik Simpan & Hubungkan. Data supervisi otomatis tersinkronisasi online!
